# 《晴天》案例：可复制的提示词

以下提示词根据实际制作过程整理，补齐了素材、叙事、画面、音频、字幕和验收要求；它们是可复用的创作简报，不是逐字会话记录，也不保证一次生成就达到成片质量。

## 1. 完整制作提示词

复制后，替换音频和歌词文件路径。若没有歌词文件，可以直接把歌词贴在消息中。

```text
使用 $painted-animation，制作周杰伦《晴天》的 40 秒水彩歌词 MV。

【素材与截取】
音频：我提供的本地《晴天》文件，路径为 <本地音频文件路径>。
歌词：我提供的歌词文本或 LRC，路径为 <歌词文件路径>。
参考当前仓库的水彩角色动画风格。
选择原曲 1:44.590–2:24.590；先检查这份音源的实际内容是否与该区间匹配。
若版本不同，找出对应的五句歌词，并重新对齐，不要硬套时码。
音乐不变速、不改调，首尾做自然淡入淡出，记录所有音频处理。
参考链接打不开时说明实际可见的信息，再依据可读取的素材继续。

【主题与故事】
主题是：雨停了，回忆还在；最后把回忆折成纸飞机放飞。
用一个橙色男孩和一个戴小花的粉色女孩，讲等待、陪伴、分别、重逢和告别。
纸飞机贯穿全片，小花、雨滴、窗框与纸张形成视觉呼应。
画面事件必须与正在唱的歌词相关：
“等到放晴”对应雨窗和独处后的希望；
“爱你很久”对应相册回忆和雨街共伞；
“距离吹得好远”对应风中长街、巴士离站和车窗视角；
“再多爱一天”对应桥上重逢和河边落日；
“说了拜拜”对应松手与暮色站台挥别。
尾音时，男孩在屋顶放飞纸飞机。

【视觉风格】
二维手绘水彩、暖纸底、颗粒、略有抖动的墨线，保留手工感。
人物外形、服饰颜色与小花标识全片一致，表情有过渡。
色彩随情绪从雨蓝、室内奶油黄，走到回忆暖粉、风雨青灰、落日橘、暮色蓝与晴空。
用远中近层次、窗框、树影、雨滴、河面、路灯、相册和生活道具增加空间细节。
主体和歌词优先清晰，不让细节抢走当前动作。

【镜头设计】
做成 13 个镜头，参考以下顺序与时间：
0–2.40：雨滴沿窗滑落，云缝出现阳光，特写。
2.40–4.70：窗边书桌，男孩抬头，窗帘展开，室内中景。
4.70–7.87：男孩拿着纸飞机，从低落变得有希望，人物近景。
7.87–10.46：俯拍相册，三张照片依次展开，夹着小花。
10.46–13.83：雨街共伞，女孩靠近，伞与人物接触关系清楚。
13.83–17.23：风中长街，两人的距离拉大，树叶有前后景速度差。
17.23–19.48：巴士驶离站台，男孩留下。
19.48–21.60：切入女孩的车窗视角，男孩在窗外远去。
21.60–24.40：桥上重逢，男孩跑近，双手与纸飞机靠近。
24.40–28.30：河边野餐、饮料和相机，太阳落下，表现短暂的一天。
28.30–31.30：双手与纸飞机特写，粉色的手松开，花瓣掉落。
31.30–35.74：暮色站台，犹豫、挥手、离开，动作配合“拜拜”。
35.74–40：屋顶放飞纸飞机，镜头随飞机抬向天空，落到纸色片尾。
每镜头突出一个主要动作，给观众理解动作的时间。
用翻页、前景遮挡、光线或构图衔接转场，不要每次都用同一种切换。

【歌词与声音】
使用我提供的准确歌词，不从听感擅自替换字句。
先对齐行级时间，有可靠时码再做逐字高亮；不确定处在交付说明中注明。
底部放清楚的中文书法字幕，配低干扰的纸色底，避免挡住手、脚和道具。
字体落地到项目中并保留许可，检查实际字符是否齐全。
以歌曲为主要声音，不默认叠加音效、旁白或新的演唱。

【实现与迭代】
先检查现有工具链并写 STORYBOARD.md，再直接制作。
复用技能里的角色、镜头、渲染与编码工具；帧内容只由时间 t 决定。
复杂静态背景可以先预绘制，人物、道具、雨、光和镜头继续按时间运动。
先看各镜头起段、中段、末段，再看关键动作连续帧和局部细节。
发现遮挡、漂浮、跳色、缺线、字幕碰撞或不自然的转场时，直接修正并复查。
镜头与字幕修改后重画；没有可靠完成证据时，不把任务标成完成。

【交付】
40 秒，1920×1080，24 fps，H.264 MP4，含原曲片段音频。
同时交付分镜预览、SRT、可编辑工程、素材来源和复现命令。
用 ffprobe 检查时长、帧率、尺寸和音视频轨道，用 ffmpeg 完整解码。
报告实际完成的抽帧、连续帧、观看和试听检查，不把自动检查当成人工试听。
保留旧版本，成片与工程使用清晰的版本名。
```

上述 40 秒、13 镜头、人物和纸飞机是本案例的选择，换题材时可以调整，不是技能的固定限制。

## 2. 用户只给音频时

```text
这是我提供的音频和歌词。请先确定约 40 秒的完整情绪段落，告诉我原曲起止时间，
然后围绕这段歌词写一个连贯的故事。可以自行选择镜头与道具，画面必须回应歌词含义。
先完成音频与行级歌词对齐，再进入逐镜头制作。
```

## 3. 画面单一时怎样迭代

本案例的实际反馈是“感觉画面比较单一，能不能丰富一些”。可以把要求进一步写清楚：

```text
当前画面有些单一。保留这 40 秒音频、歌词时码、角色和纸飞机，重新设计视觉节奏。

请先识别反复出现的背景、景别和人物姿势。
把同一段情绪拆成有联系的事件，增加室内外、俯拍、车内视角、人物近景和道具特写。
每句歌词至少对应一个可看懂的事件，动作之间要有因果或回忆关系。
增加雨滴、风、树叶、窗帘、水面和光线等与场景有关的运动。
保留停顿与留白，不用持续切镜头或堆粒子替代叙事。
检查新分镜，修复人物遮挡、手与道具接触、跳色和字幕问题，导出新的版本。
```

本次因此从八镜头改成十三镜头，新增相册、街角、车窗、河边、手部特写与屋顶。修改前后的对应关系见 [案例说明](README.md)。

## 4. 让动作更有表演感

```text
重点调整人物表演：每个重要动作要有准备、动作本身和余势。
抬头前先停顿，靠近时让视线和身体同步，递出纸飞机时保证手与道具接触，
告别前给一个犹豫的停顿，然后挥手、转身和离开。
用连续帧检查这些过程，不只挑好看的单帧。
```

## 5. 修正字幕

```text
保留当前构图，检查歌词与音频的对应关系。
先修正行级起止，再核对逐字高亮；没有可靠证据时标明估计，不要假装逐字准确。
字幕放在安全区域，底色不过强，避免挡住手持物和关键动作。
检查实际渲染的中文字形，缺字时更新本地字体子集并保留字体许可。
```

## 6. 调整成竖屏

```text
把这支视频改成 1080×1920 竖屏，保留故事、音乐片段和歌词。
重新安排相机、人物站位、场景层次和字幕安全区。
相册、双人关系、车窗和手部特写分别重构，避免直接裁掉重要信息。
每个镜头抽帧检查，导出独立竖屏版本，保留横屏原版。
```

此提示词说明后续适配方式；本仓库交付的《晴天》仍为横屏，未声称已经完成竖屏验收。

## 7. 换成另一首歌

```text
沿用这套水彩视觉与制作方法，为我新提供的歌曲制作一支歌词短片。
重新选段、对齐歌词并设计故事；不要照搬《晴天》的时间码、桥段或角色关系。
根据新歌词选择贯穿道具和色彩变化，给出该作品自己的 STORYBOARD.md。
复用渲染工具与检查方法，交付 MP4、字幕、源码和来源说明。
```

## 8. 只需要复现已有成片

```text
按 examples/qingtian/README.md 复现已有案例，不重新设计分镜。
检查依赖和音频文件，先渲染少量镜头确认字体、布景与字幕正确，再渲染全片。
使用已有的歌词时码和 24 fps 设置。输出新的 MP4，并核对轨道、时长、帧数和完整解码。
```
