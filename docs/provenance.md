# 来源、迁移和发布范围

本项目是独立维护的 Codex 适配版，基于 [opus-video-skills 的固定提交](https://github.com/tuzhechen2005/opus-video-skills/tree/59744a69c7b916cfbe4c4ec84006b0c2f5e2fde1)。上游将 Claude Code 与 Opus 作为制作环境；这里提供 Codex 技能入口，保留原始画面风格、模板和署名。

## Codex 适配

- 中文 `SKILL.md`、`agents/openai.yaml`，支持自动选择和显式调用。
- 根据实际 skill 目录定位脚本，不依赖某台电脑的绝对路径。
- 初始化前检查 Node、npm、rsync、Chrome 和 ffmpeg；要求新目录，避免覆盖作品。
- 渲染缓存记录源码与本地画面资产签名、帧率、帧数及音频配置。
- 编码前检查帧序列，正确传播 ffmpeg 错误，清理浏览器进程。
- 创作规则允许按用户要求加入中文、字幕与品牌风格。
- 多 Agent 章节委派仅在用户授权后使用；制作视频不隐含发布网站或外部消息权限。

## 《晴天》案例增加的内容

- 本地书法字体子集、已整理的歌词时码与逐字高亮。
- 十组预绘制水彩布景、十三个镜头、不同景别与视角、动态前景和转场。
- 背景预绘制脚本，避免每帧重复绘制复杂静态场景。
- 镜头起段/中段/末段检查、连续动作检查和最终 MP4 抽帧。

案例中的歌词模型对齐发生在单次制作过程中。发布包保留结果，不把完整语音模型环境或自动逐字识别描述为技能自带能力。

## 同步到发布模板的绘制修复

`painted-animation/template/src/core.js` 的两点线段使用直线模式：p5.brush 的曲线样条路径需要至少三个点，原先部分雨丝、栏杆和水纹未画出。

`painted-animation/template/src/brush-compat.js` 在 p5 与 p5.brush 混合绘制时重新绑定着色器，避免 p5 缓存的当前程序与实际 WebGL 状态不一致。兼容层位于项目内，依赖版本及锁文件未修改。

这些修复来自实际案例检查。不要把某个画面的色块问题全部归因于同一个底层问题；本案例还通过调整松手特写的构图消除了局部跳色。

## 保留的边界

通用模板默认横屏并加载远程字体。案例已经本地化字体，但不会自动为所有新作品处理字体授权、字符子集、竖屏布局或歌词对齐。缓存签名不追踪远程字体和手动修改的 `node_modules`；发生这些变化时需要强制重画全片。

原模板和参考材料中的 Claude、Read 工具名、历史机器性能描述其原始环境；执行以中文 `SKILL.md`、当前工具和本机抽样结果为准。
