# 《晴天》40 秒水彩歌词动画 · 丰富分镜版 v2

打开成片 `qingtian-40s-v2.mp4` 即可播放。源工程用于修改角色、分镜和字幕；上游 README 与 MIT LICENSE 保留原文，当前作品以本说明和 STORYBOARD.md 为准。

本版把原先八个镜头扩展为十三个镜头，加入雨窗、室内、相册、共伞街角、风中长街、车站、车窗、小桥、河边野餐、松手特写、暮色站台与屋顶。音乐和歌词时码沿用第一版。

## 内容

- `src/scenes/qingtian-rich.js`：十三个镜头、人物表演、动态前景和转场。
- `src/scenes/qingtian-world.js`：十组水彩布景及素材加载。
- `src/scenes/qingtian.js`：复用的角色、道具和绘画工具；旧镜头注册会由新版替换。
- `src/brush-compat.js`：修复 p5.brush 与 p5 混合绘制时的着色器状态，使颜色和笔画正确显示。
- `src/core.js`：绘画与镜头工具；两点线段使用直线模式，恢复雨丝、栏杆和水纹。
- `assets/rich/`、`bake-backgrounds.mjs`：预绘制布景及其生成脚本。
- `src/config.js`：40 秒时长、半速节拍与音频路径。
- `src/qingtian-captions.js`、`src/lyrics-data.js`：字幕、逐字高亮和片头片尾。
- `assets/qingtian-40s.wav`：本次使用的 40 秒音频，不包含完整歌曲。
- `assets/lyrics.json`、`assets/qingtian.srt`：歌词与片段相对时码。
- `assets/qingtian-brush.ttf`：字幕所需的本地书法字体子集。
- `STORYBOARD.md`：逐句歌词与画面的对应关系。

## 重新渲染

需要 Node.js 22.12 或以上版本、Chrome/Chromium、ffmpeg。进入解压后的工程目录执行：

```sh
npm ci
node render.mjs --frames --workers=4 --fps=24
node render.mjs --encode --out=out/qingtian-40s-v2.mp4
```

Chrome 不在标准路径时，渲染命令添加 `--chrome=/完整路径/Chrome`。布景 PNG 已包含在工程中；若修改 `qingtian-world.js` 或布景使用的绘画工具，请先运行 `node bake-backgrounds.mjs`，再重新渲染。仅修改人物动作、镜头和字幕时，直接重新运行 `--frames` 即可；渲染器会根据输入指纹重建缓存。原始项目保留 package-lock.json，未为本次视频修改依赖版本。

音乐取自用户提供的 FLAC，原曲区间 1:44.590–2:24.590。歌词取自用户发来的文本；逐字时码是本机音频对齐的估计，未作人工逐字听校。音乐没有变速或改调。

视觉检查覆盖各镜头首、中、末帧，松手连续帧，以及转场、共伞、车窗、重逢、告别和片尾细节。完整 MP4 的解码和音视频参数检查记录在交付说明中；这些检查不等于人工从头到尾观看和试听。
