- 两个技能通过 Codex `quick_validate.py` 格式验证。
- 两套渲染回归测试共 14 项通过：缓存、缺帧、帧率、音频继承、进程失败、浏览器清理与非整数帧时长。

- 检查新增文档与技能入口的本地链接，确认依赖版本与原有锁文件保持一致。

发布检查复用了已安装的 npm 依赖。模板渲染与案例抽帧不是再次重渲染整支 MV；成片验证来自上面明确记录的最终交付版本。

## 环境与边界

本机环境为 macOS Apple Silicon、Node 24.19.0、Chrome、ffmpeg 9.0.2。Linux 和 Windows 的实机效果尚未验证。

歌词逐字时间来自本机音频模型对齐估计，未人工逐字听校。抽帧、连续帧与完整解码不等于人工从头到尾观看或试听。

抖音参考页面未能提供可读取视频，水彩视觉依据上游仓库示例和本次创作分镜。不同机器重渲染可能因浏览器、GPU、字体和编码器产生差异，不保证文件哈希一致。

音乐、歌词、字体等素材范围见仓库 [NOTICE](../../NOTICE.md)。
